# 128 KiB FIDO store expansion

The user requested increased capacity after board telemetry stabilized at
8.4 KiB heap reservation and 148 KiB uncommitted RAM with the 64 KiB image.

## Implementation

- Engine image increased to 131,072 bytes. The existing 1 MiB private SD region,
  USB geometry, engine wrapping key derivation and independent bank keys remain.
- Snapshot v2 uses 18 metadata sectors and 256 payload sectors per bank, plus
  the manifest. v1 reads retain the original 9/128-sector geometry.
- Authenticated legacy file lists are validated and relocated in RAM. Credential
  payloads remain byte-for-byte unchanged. Open performs no writes; the next
  commit writes v2 to the alternate bank. Invalid lists fail closed.
- Downgrade is unsupported: old firmware cannot read v2 and may select a stale
  surviving v1 bank. Do not use old firmware after saving expanded snapshots.
- Fixed RAM including stack reservations is about 427.6 KiB; the linker leaves
  92.4 KiB for the heap. At the user's previously observed 8.4 KiB reservation,
  about 84 KiB would remain uncommitted. New-build runtime usage is not measured.

## Measured desktop capacity

| Profile | 64 KiB | 128 KiB |
| --- | ---: | ---: |
| Same site, 100-character usernames, 4-byte user IDs | 44 | 103 |
| Same site, short usernames, 4-byte user IDs | 48 | 112 |
| Distinct sites, email/display name, 32-byte user IDs | 45 | 107 |
| Distinct sites, email/display name, 64-byte user IDs | 44 | 104 |

Each uses ES256 resident credentials and checks an existing signature after
full-store rejection and reopen. These are fixture capacities, not universal
guarantees. Nonresident SSH credentials do not consume a resident slot.

## Validation

- Full normal desktop suite: 37/37 passed.
- Legacy fixture generated by the previous engine: two resident credentials and
  one nonresident credential. Independent python-fido2/cryptography verification
  passed after expansion, discovery, new registration and reopen.
- 146 migration write/sync interruption cases and 702 expanded-snapshot fault
  cases passed, including dropped unsynchronized writes. USB/header boundaries
  remained unchanged. Authenticated malformed legacy lists are rejected.
- ARM FIDO/debug firmware built and UF2 generated. No device flashing,
  initialization, reset or real-account changes performed.
- Focused ASan/UBSan suite: 7/7 passed (`detect_leaks=0`; no leak-check claim).
  Covers adapter, store faults, migration, engine and encrypted client suites.
  Physical migration, memory/load measurements and power-fault acceptance remain
  board checks.
