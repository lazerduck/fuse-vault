# Unified UI and button conventions — 2026-09-21

Follow-up to the first behavioral polish pass. The user identified inconsistent
FIDO styling and requested conventional navigation with concise button hints.

FIDO request, verification, credential list/delete/empty views, destructive
confirmations, unlock-method and encryption menus, failure policy and error views
now share header/footer separators and highlighted choices. Repeated prose button
instructions are replaced by Back/Select icons with contextual action labels.
Long RP approval labels retain all five 25-character content rows; approval still
requires Select, and Back rejects. Destructive menus still default to Cancel.

Controls:

- Up/Down selects an item or credential.
- Left/Right changes the selected setting/cipher or pages credential text.
- Select enters a menu or acts on the highlighted item.
- Back steps out; at unlocked home it submits the existing lock operation.
- Normal credential entry retains its method-specific behavior. FIDO credential
  Back cancels verification, as before. Home Left/Right still rotates the display.

Failure policy now has Attempts, Action and Review rows; selecting a value row
advances focus, and selecting Review opens the existing confirmation. Cipher
removal is an explicit menu item rather than a hidden Left-button action. At least
one cipher layer is retained. No storage formats, credentials or USB locking
semantics changed; the home shortcut has the same eject-before-lock requirement.

Validation:

- Full desktop suite: 35/35 passed.
- UI and FIDO adapter ASan/UBSan: 2/2 passed, with leak detection disabled for the
  existing tracing limitation.
- Composite FIDO and FIDO-disabled firmware builds passed.
- Inspected [30 rendered screen states](ui-style-20260921.png). Generated with
  `python3 tools/ui_preview.py`, using the actual shared C renderer and synthetic
  data. Hardware readability/button feel remain untested.
- Added behavioral checks for Back locking only at home, no duplicate busy
  submission, selection versus editing, explicit cipher removal and directional
  input never approving a FIDO request.
